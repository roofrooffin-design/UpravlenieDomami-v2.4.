# Управление домами — единый патч 2.5

## Фактически включено в исходники
- Android WebView-проект на основе патча 2.4 (Gradle, Java, локальный HTML/JS).
- Обновлённая тёмно-синяя/золотая тема основных элементов и навигации.
- Главный экран с тремя карточками домов и исходными утверждёнными изображениями: Ярославка, Монолит, Баня.
- Сохранены локальные функции 2.4: задачи, календарь приездов, строительные работы, чат, оборудование, журнал, фотографии, расходы, уведомления, резервное копирование, контакты, конструктор разделов.
- Сохранён единый справочник сотрудников и приглашённых специалистов: поиск по имени, должности, телефону и объекту, фото, редактирование.
- Сохранён локальный помощник для распознавания команды создания раздела с подтверждением; добавлена попытка голосовой диктовки через SpeechRecognition, если поддерживается WebView.

## ВАЖНО: не реализовано и не следует выдавать за готовое
- Полноценный OpenAI GPT через защищённый сервер; обработка естественного языка для произвольных действий, ответы, создание задач/расходов/встреч, доступ к справочнику через GPT.
- Надёжный двусторонний голосовой диалог, аудиоответы и гарантированное распознавание в Android WebView.
- Общая база данных Android/iPhone, серверная авторизация, права доступа, синхронизация, уведомления и аудит.
- Универсальные динамические поля и произвольная вложенность разделов (сейчас локальный упрощённый конструктор).
- Полное пиксельное воспроизведение ранее утверждённых макетов на каждом экране: в 2.5 применена общая палитра и обновлена главная страница, остальные экраны требуют UI-доработки.
- Настоящие профили работников с гарантированным сохранением фото на сервере, мессенджеры, полноценная история платежей специалистов.
- Сборка APK и тестирование на реальном устройстве (не выполнены в этом пакете).

## Полное согласованное ТЗ для Android и iOS

### Дизайн
Тёмно-синий интерфейс, золотые акценты, утверждённые карточки трёх домов, без изменения утверждённых изображений. Главный экран: карточки Ярославка/Монолит/Баня, «Добавить объект», задачи, календарь, сотрудники, специалисты, расходы, отчёты, нижняя навигация с GPT. Индивидуальный дом: задачи, обслуживание, инженерные системы, уборка, сад, техника, расходы, документы, фото/видео, журнал работ. Не изменять утверждённые макеты без согласования.

### Единый справочник
Один человек — одна карточка. Штатные сотрудники и приглашённые специалисты, имя, должность/специальность, телефон, WhatsApp/Telegram/email, фото (камера/галерея/файл), объекты, активный/архивный статус, задачи, работы, оплаты, документы. Поиск по имени, фамилии, специальности, должности, телефону, объекту; фильтры по типу. Быстрый звонок/сообщение. Только администратор редактирует критичные данные.

### GPT-помощник
Текст и голос; поиск по справочнику, задачи и исполнители, календарь и напоминания, расходы, отчёты, создание произвольных разделов/подразделов и полей. Предпросмотр действия и подтверждение перед сохранением, особенно финансы, удаления, права. Запись автора и аудит; GPT не должен обходить разрешения. API-ключ хранится только на сервере, не в Android/iOS.

### Конструктор
Общие и привязанные к объекту разделы, произвольная вложенность, типы полей (текст, дата, деньги, задачи, фото, документы, исполнитель), сортировка, архив, история изменений, права.

### Данные и безопасность
Общая серверная база и API для Android/iOS, индивидуальные учётные записи, роли администратора (Олег, Виталия) и сотрудников (включая Манон) с ограниченным доступом. Защищённое хранение файлов и персональных данных, аудит, резервные копии, синхронизация и работа с конфликтами. Текущий локальный вход демонстрационный и не защищает данные.

### iOS
Нативный iOS-клиент или общий кроссплатформенный интерфейс с тем же дизайном, контрактом API, сущностями, правами и синхронизацией. APK не переносится на iPhone.

## Как собрать Android
Открыть `UpravlenieDomami-Android-2.5` в Android Studio, проверить версии Android SDK/Gradle и запустить сборку. Для GitHub Actions скопировать `.github/workflows/android.yml` в корень репозитория. При загрузке на GitHub распаковать архив и сохранить дерево каталогов.

## Ограничения локальных данных
Данные остаются в localStorage конкретного WebView; синхронизации нет. Изображения и записи могут упереться в лимиты хранилища. Регулярно делать резервные копии. Перед публикацией убедиться в отсутствии персональных данных, паролей и API-ключей.

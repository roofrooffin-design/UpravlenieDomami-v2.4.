# Единый патч 2.4 — Управление домами

Основа: предоставленный исходный проект Android 2.4 (WebView + локальный HTML/JS). Этот архив содержит **обновлённые исходники**, не установочный APK.

## Реально внесено в исходный код
- Единый локальный справочник сотрудников и приглашённых специалистов: создание, редактирование, удаление, фото из галереи, поиск по имени, должности, телефону, объекту, фильтр категории, звонок.
- Локальный конструктор подразделов: создание общих разделов или разделов по дому, выбор полей, проверка дубликатов, подтверждение, удаление.
- Экран «GPT-помощник» с **ограниченным локальным распознаванием команды** создания подраздела и подтверждением. **Не является подключением к OpenAI API**.
- Добавлены три утверждённые иллюстрации карточек домов в assets (пока не подключены к главному экрану).
- Сохранены существующие задачи, календарь, фото, финансы и резервное копирование.

## Не реализовано в этом патче
- Полный утверждённый тёмно-синий/золотой редизайн экранов.
- Настоящий GPT через OpenAI API, голосовые команды к GPT, создание задач и расходов из чата.
- Синхронизация Android/iPhone, серверная авторизация, настоящая защита прав, push-уведомления.
- Универсальное динамическое хранение записей внутри новых подразделов.
- APK не собран и на устройстве не протестирован.

## Важные ограничения безопасности
- Вход и роли в исходной версии клиентские, поэтому НЕ подходят для защиты финансов или персональных данных при реальной эксплуатации.
- Все записи в localStorage: необходимо регулярно делать резервные копии; на разных устройствах данные не синхронизируются.
- Для полноценной версии нужен сервер, БД, роли с проверкой на сервере и защищённое хранилище ключа OpenAI.

## Разработчику
1. Открыть `UpravlenieDomami-Android-2.4` в Android Studio.
2. Проверить Android Gradle Plugin и SDK, выполнить сборку и инструментальные тесты.
3. Реализовать синхронизацию, аутентификацию, серверный GPT, полноценный конструктор и утверждённый UI.
4. Для iOS использовать тот же контракт API и модель данных; APK не переносится напрямую.

### Модель контакта
`{id, name, role, phone, kind: "Сотрудник"|"Специалист", homes: ["Ярославка", ...], photo}`.

### Модель подраздела
`{id, home: "Общий раздел"|"Ярославка"|"Монолит"|"Баня", name, fields: string[]}`.
